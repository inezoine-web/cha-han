# 業務用鍋探索の一振り評価と20回再生の不一致

Date: 2026-08-22

## 結論

上位候補が20回再生で1〜2回しか大きく混ざらず、その後に片側へ偏るのは再生だけの問題ではない。現在の探索は、**毎回初期化した配置の最初の一振り**を20種類について採点している一方、再生は**同じ粒の着地点を次の開始位置にして20振りを連成**している。したがって探索が保証しているのは「複数の初期配置から1回目が良い」ことであり、「着地分布が次の振りでも良い状態を保つ」ことではない。

加えて、現在の「ランダム配置」と「有効シャッフル」には、目視で問題になった片寄りを見落とす性質がある。

1. 配置生成は21粒を独立に無作為配置していない。等間隔の列へ、全体の平行移動、`0.72 ... 1.00` の拡縮、小さなジッターを与えてソートしている。このため各試行は初めから鍋幅の大部分へ比較的均等に広がり、片側に固まった着地後の状態を試験しない。
2. 順序反転率は、その一振りで離床・回収された粒同士の離床角と着地角の順序だけを見る。鍋内の粒群全体が片側へ寄ったか、前周期と同じ少数粒だけが動いたか、同じ周期写像へ収束したかは見ない。
3. 比較可能率は「回収イベントに現れた固有粒ID数 / 21」なので少数粒だけの偶然は抑えるが、動かなかった粒を含む最終分布の幅・重心・左右占有率は抑えない。
4. 集約の中央値と下位20%点は20個の**独立した一振り**の頑健性であって、20振りの時系列における最低値や後半の劣化ではない。

つまり、初期配置の乱数化は実装されているものの、検証したかった外乱（任意の米配置）と実際に生成した外乱（ほぼ一様な列の平行移動・拡縮）が一致していない。また、一振りの順序反転を反復可能な混合と読み替えたことが評価対象の取り違えだった。

## コード上の経路

- `paperInitialPositions(trial)` が各試行の初期位置を生成する。
- `extendPaperTrials()` は常に `simulatePaper(..., trial, 1)` を呼ぶため、各配置を1周期だけ評価する。
- `aggregatePaper()` はその20個の一周期スコアを集約する。
- 一方「選択軌道を20回再生」は `replayPaper(..., 0, 20)` を呼び、各着地角 `r.z = landing` を次周期へ引き継ぐ。

この非対称性により、探索中には一度も採点されない2〜20周期目で分布が偏っても順位は下がらない。

## 追試

`analyze-order.mjs --long-run` を追加し、以前に目視選択した13軌道を同じ初期列から20周期連成して、周期別の回収イベント数・現行方式の有効シャッフル・20周期後の生存粒数と角度分布を表示した。

```sh
node models/professional-wok/analyze-order.mjs --long-run
```

この追試では、たとえば旧順位33は20周期後の粒角度幅が `0.890 rad`（鍋の全角度幅 `2.4 rad` の37%）まで縮んだ一方、現行の有効シャッフルは5周期目以降も `100%` と表示された。また旧順位29・43は20周期後に `13/21` 粒、順位100は `11/21` 粒しか残らなかった。これは現行指標が「一振り内の回収粒の順序反転」を測る限りでは計算どおりでも、粒群の偏在、損失の累積、反復後の混合可能性を表していないことを示す診断例である。なお、これは画面表示値へ丸めた旧13候補であり、新しい探索結果そのものの順位再現ではない。

## 修正方針

評価関数の重みだけを調整するより、探索時の試行単位を目的へ合わせる必要がある。

1. 各候補・各初期配置を少なくとも数周期連成し、ウォームアップ後（例: 3〜10周期）の各周期を採点する。
2. 各周期の順序反転に加え、離床した固有粒率、各粒の連続不参加回数、累積回収率を記録する。角度幅と重心は原因分析用に観測するが、それ自体を良し悪しにしない。
3. 後半周期の最低値または下位分位を候補スコアへ入れ、最初だけ良い軌道や固定的な周期写像へ収束する軌道を落とす。
4. 初期配置には現在の一様列の摂動だけでなく、片側クラスタ、中央クラスタ、複数クラスタを明示的に含める。完全独立乱数だけでは粒の重なりが生じるため、最小間隔を保つ層化配置として生成する。
5. 長期評価は計算量を増やすが、第一段階も最低3周期は連成する。後段で周期数と配置数を増やし、必要なら候補数を減らして計算量を調整する。

原因切り分け後、この方針をブラウザの探索へ実装した。現在は「長期にわたり大部分の米が離床へ参加できること」を合格条件にし、その中で順序反転の質を順位付けする。

## 評価単位の再検討: 一振りではなく連続調理

以前の3周期評価は、少なくとも着地状態を次周期へ渡していた点では現在の一振り評価より目的に近かった。ただし、3回それぞれの離床・回収・反転を採点するだけでは「3回を通じて混ざったか」と「同じ粒が同じ往復を3回繰り返したか」を区別できない。また3周期は、初期状態だけ良い軌道が崩れるまでの時間として短い可能性がある。したがって単純に旧スコアへ戻すのではなく、**連続した複数振りを一つの調理試行として評価する**のがよい。

試行は、たとえば2周期のウォームアップと、それに続く6周期の評価区間で構成する。ウォームアップも物理状態と損失には含めるが得点対象外にし、初期の等間隔配置が直接得点になるのを避ける。評価区間では次の三層を別々に測る。

### A. 一振りごとの混合

- 各周期で回収された固有粒率と、離床から着地までの通常・距離加重順序反転率を求める。
- 6周期の中央値だけでなく下位25%点を使い、1〜2回だけ大きく返す候補を落とす。
- 同じ粒だけが参加し続ける場合を検出するため、周期ごとの参加粒ID集合に加え、評価区間全体で一度でも参加した粒の割合も記録する。

### B. 一振り後の可動性維持

- 重心が鍋中央から離れることや、左右が非対称になること自体は減点しない。実調理ではお玉でならす操作もあり、偏った領域でも離床と交換が継続するなら有効な鍋振りである。
- 各周期で離床した固有粒率に加え、2〜3周期の移動窓で一度でも離床した生存粒率を求める。単周期では休んだ粒も、次の振りで参加すれば停滞扱いにしない。
- 各粒について連続して離床しなかった周期数を追い、長い不参加列を持つ粒の割合を測る。これが「離床しづらい場所へ取り残された米」の直接的な指標になる。
- 角度幅、重心、左右占有は得点ではなく、どの位置で参加率が落ちたかを説明する診断値として保存する。同じ重心位置でも参加率が高い候補と低い候補を区別し、位置そのものへ良否を割り当てない。
- 損失粒を除外して参加率だけを計算すると「都合の悪い粒を捨てる」解になるため、累積生存率を独立した必須条件にする。

### C. 試行全体を通じた混合

単純な「初期順序と最終順序の反転率」だけでは、全体を一度裏返した候補が満点になり、2回裏返して元へ戻る候補が0点になる。そこで、粒ペアごとに周期末の左右関係を追跡し、次を併記する。

- **関係変化回数**: 各粒ペアの前後関係が周期間で何回変わったか。繰り返し混ざることを測る。
- **交換経験率**: 評価区間中に一度でも前後関係が変わった粒ペアの割合。常に同じ近所だけが交換される候補を区別する。
- **移動範囲**: 各粒が評価区間に経験した着地順位または角度の範囲。全粒が鍋内の異なる場所を経験したかを見る。

距離加重は、初期順位ではなく関係が変わる直前の順位距離を用いる。これにより、同じ完全反転を毎回繰り返すだけの周期運動は関係変化回数だけが高くなっても、参加の持続性や移動範囲と組み合わせて判別できる。

### 合否と順位を分ける

異なる性質を一つの加重和へ直ちに押し込むと、非常に高い反転点が片寄りや損失を相殺する。最初は次のような二段階判定が安全である。

1. 累積生存率、周期ごとおよび移動窓内の参加率、長期不参加粒率について最低条件を満たさない候補を不合格にする。重心や左右占有は合否条件にしない。
2. 合格候補だけを、一振りごとの混合下位点、交換経験率、関係変化回数、移動範囲、運動効率で順位付けする。

探索計算量については、全2,500件を一振りだけで足切りすると今回と同じ盲点を残す。第一段階から最低3周期を連成し、上位300件を複数配置の5周期、上位100件をクラスタ配置を含む20周期で評価する。8周期評価の試行では合格した上位候補が20回再生の後半で全粒を失う例を確認したため、最終評価を実際の再生長へ合わせた。片側クラスタは「中央へ戻るか」ではなく、その位置から離床参加と交換を継続できるかを試す。実行時間が長ければ候補数や配置数を減らし、連続周期を一振りへ戻さない。
