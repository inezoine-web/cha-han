# 目視選択した業務用鍋軌道の初期分析

Date: 2026-08-22

## 目的

業務用モードの2,500軌道探索結果を再生し、「3周期のそれぞれで米がほぼ安定して舞い、米の前後が入れ替わっていくように見える」と目視で選んだ13件について、共通範囲と相関の有無を確認する。

これは同じ1回のランダム探索の上位100件から、人が結果を見て選んだ**探索的な標本**である。無作為標本でも独立した検証データでもないため、以下の相関係数は傾向を整理する記述統計に限り、母集団の因果関係や有意性を示さない。

## 見える傾向

### 1. 最も明瞭なのは「負の位相差の狭い帯」

- `φ` は `-0.99 ... -0.69 rad`、平均 `-0.83 rad`（標本標準偏差 `0.09 rad`）に集中した。
- 探索範囲全体は `-π ... +π rad` なので、選択例がすべてこの約 `0.30 rad` 幅へ入ったことは、少なくとも現モデルとこの目視基準では強い共通性である。
- 3 Hzでは、位相差 `-0.83 rad` は1周期の約13%に相当し、時間差の大きさでは約 `44 ms` である。ただし `φ` の正負をそのまま「並進が44 ms先行」と読むには、コード中の余弦の定義と二リンク角の意味を併記する必要がある。

### 2. 両振幅とも探索範囲の上側だが、同じ値である必要はない

- `A1` は `0.30 ... 0.40 rad`、平均 `0.359 rad`、`A2` は `0.32 ... 0.39 rad`、平均 `0.368 rad` だった。探索範囲 `0.05 ... 0.40 rad` に対して、どちらも上端寄りである。
- 一方、13件内の `A1` と `A2` の Pearson 相関は `r = 0.03` で、ほぼ線形相関がない。したがって「A1を上げればA2も同じだけ上げる」という関係はこの標本からは言えない。
- 差 `A2 - A1` は `-0.04 ... +0.09 rad`（平均 `+0.008 rad`）。振幅が概ね近い軌道は多いが、どちらが常に大きいという符号関係もない。

### 3. パラメーター間には「帯の傾き」らしきものがあるが未確定

13件内では `φ` と `A1` が `r = -0.62`、`φ` と `A2` が `r = +0.55` だった。より負の位相側でA1が大きく、A2が小さくなる補償関係の可能性はある。しかし、標本数が少なく、上位順位と目視の二重選別を受け、値も画面表示桁へ丸められているため、現時点では「局所探索すべき斜めの尾根」という仮説に留める。

### 4. 「安定して3回舞う」という目視判断は周期間ばらつきと整合する

- 各軌道の3周期の離床数について、周期内平均は `15.7 ... 22.3 / 21標本`、最少周期は `13 ... 21` だった。21を超える値は、同じ標本が周期内に再離床し得る現在のイベント数定義による。
- 3周期の離床数の標準偏差とリアル度の相関は `r = -0.71` だった。これは上位ほど周期ごとの離床が揃う傾向を表すが、リアル度自体が各周期の適合度と最少値を採点しているため、独立した発見ではなく採点式の反映でもある。
- 回収率は `70.2 ... 95.5%`、平均 `84.3%`。高さは1件を除き `17.2 ... 19.9 cm` に集まり、選ばれた見た目は「極端に高く飛ばす」解ではない。

## 現段階の結論

相関性が全くないわけではない。目視選択例を最も短く表す暫定領域は、**`φ ≈ -0.8 ... -0.9 rad`、`A1 ≈ 0.35 ... 0.40 rad`、`A2 ≈ 0.35 ... 0.39 rad`** である。ただし本質は各パラメーターの単独値より、負の位相差と十分な二つの振幅の組合せにある可能性が高い。

順位3・4・7・17のようにA1が `0.32 ... 0.35 rad` でも目視上よい例があるため、上記は合格境界ではなく密な候補域である。またリアル度との単純相関は、採点式が高さ・角移動・各周期離床・回収を直接含むので、人の目による外部妥当性の証明には使えない。

## 次の検証

1. `φ = -1.00 ... -0.65`、`A1 = 0.30 ... 0.40`、`A2 = 0.30 ... 0.40` を等間隔格子で走査し、ランダム抽出密度の影響を除く。
2. 人には順位とパラメーターを隠し、「3回の安定」「前後の入れ替わり」「高さ」「回収」の項目を別々に採点してもらう。
3. 選択例だけでなく、同じ順位帯の非選択例も保存し、選択／非選択を分ける特徴を比較する。
4. 現在の角移動は着地点の絶対差の平均であり、米群の前後交換を直接測っていない。初期順序に対する着地順序の反転率、または順位相関を新しい指標候補とする。
5. 同一パラメーターを初期配置や粒標本数を変えて再試行し、3周期の安定が固定された21地点に過適合していないか確認する。

## 追試: 離床から着床までの順序反転

目視した「前後が入れ替わる」を直接確かめるため、表に転記した13件の表示値を `analyze-order.mjs` で再計算した。各回収イベントについて離床角と着床角を保存し、同じ周期に回収された異なる2粒の全組合せを比較した。離床時と着床時で角度の大小関係が逆になった組を「反転」と数える。

- 反転率 `0%` は全ペアの順序維持、`100%` は完全な逆順を表す。無作為な着地順なら期待値は概ね `50%` である。
- 同一粒が同じ周期内に再離床した場合、その粒自身との組合せは除外する。
- 周期をまたぐ粒同士には同時の前後順序がないため比較せず、3周期の集計も周期内ペアの分子・分母を合算する。

### 遠い粒の交換を重くする

通常の反転率は隣同士の交換も端同士の交換も1件と数える。このため、離床時の並びに `0 ... n-1` の順位を付け、反転したペアへ離床時の順位距離 `|ri-rj|` を重みとして与える**距離加重反転率**も計算した。

```text
距離加重反転率 = Σ(反転ペアの離床順位距離) / Σ(全比較ペアの離床順位距離)
```

10粒なら全ペア距離の合計は165である。隣だけを5組交換した `1032547698` は `5 / 165 = 3.0%`、全て逆順の `9876543210` は `165 / 165 = 100%` になる。したがって、質問にある「近所で少し交差」より「ホットケーキのように全体が反転」を明確に高く評価できる。

13件をさらに合算すると、比較可能な5,338ペア中1,666ペア、**31.2%**で順序が反転した。周期別には1周期目 `28.5%`、2周期目 `32.2%`、3周期目 `37.6%` だった。したがって「全体が毎回きれいに裏返って完全な逆順になる」とまでは言えないが、**目視した入れ替わりは実際に相当数の粒ペアで起きている**。単なる平均着地角の移動より、狙っている現象へ近い評価量である。

距離加重では全距離35,707中、反転ペアの距離合計が7,416で、13件合算は **20.8%** だった。周期別には1周期目 `17.9%`、2周期目 `20.5%`、3周期目 `34.4%` である。通常反転率より低いため、現状は遠方同士の大反転より近隣交換が多い。一方、順位29・33・43の後半周期では距離加重値も高く、目視候補間の質の差を分けられる可能性がある。

一方、3周期目の `0 ... 60%` という広がりは、回収イベントが2件しかない順位100を含む少数標本の影響を強く受ける。次回の評価関数へは、生の反転率だけを加えるのではなく、(1) 比較可能な回収粒数の最低条件、(2) 各周期の反転率、(3) 3周期の最低値または幾何平均を組み合わせ、「少数だけ回収して偶然逆順」の高得点化を防ぐのがよい。

なお、元データは画面の2桁表示から転記した値であり、探索時の内部値ではない。この再計算の回収数は元表と一部ずれるため、数値は丸め済みパラメーターに対する追試である。今後は探索結果をJSONで保存して厳密値を解析する必要がある。
