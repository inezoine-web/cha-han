# 業務用中華鍋・論文再現モデル

## 目的と出典

Ko & Hu, “The physics of tossing fried rice” (2020), DOI `10.1098/rsif.2019.0622` の業務用鍋モデルを、家庭用片手鍋モデルの前段となる比較実験として実装する。原論文 PDF は `docs/rsif.2019.0622.pdf` に保存している。

## 実装した物理

- 鍋断面は論文の実測値（曲率半径 `L = 0.20 m`、幅 `0.37 m`、深さ `0.13 m`、半開口角 `ζmax = 1.2 rad`）による円弧とする。提供写真も、平らな縁から滑らかに丸底へつながる側面形状の定性的な確認に用いた。
- 鍋はコンロ縁との接触を保つ、長さ `L` の二リンク運動とする。角度は論文式 (3.1) の `θi(t) = θ̄i + Ai cos(2πft + φi)`、位置は式 (3.2) で計算する。
- 円弧上の21地点について、重力加速度と鍋表面加速度の差を内向き法線へ射影し、論文式 (3.5) を満たした最初の時刻に離床させる。
- 離床位置と速度は鍋面から引き継ぎ、空気抵抗と粒同士の衝突を無視して、重力 `9.81 m/s²` だけで式 (3.6) を積分する。刻み幅は論文と同じ `0.002 s`。
- 粒と移動中の鍋中心との距離が再び `L` になった時点を式 (3.7) の着地とし、開口角の外なら回収失敗とする。着地後の滑走は論文モデルの評価対象外だが、回収した標本の着地角度は次周期の開始位置へ引き継ぐ。離床条件がいったん不成立になった後に再離床でき、1セット3周期を連続して追跡する。ただし、着地後の接線速度、滑走、粒子間衝突は引き継がない限定的な連成である。

## 論文からの意図的な拡張

`付着抵抗 a` は、乾燥粒子で引力なしとする原論文にはない探索用パラメーターである。離床に必要な法線方向の相対加速度へ `a` を閾値として加える。`a = 0` が論文そのままの条件であり、結果画面でもこの差を明示する。

ランダム探索は周波数を `f = 3 Hz`、付着抵抗を `a = 1 m/s²` に固定し、振幅 `A1, A2` と位相差 `φ` を振る。一振りの有効シャッフルは、通常の順序反転率30%と、離床時に遠かった粒同士を重くする距離加重反転率70%を、目視選択例の暫定目標値40%・30%で正規化し、さらにその一振りで比較可能になった固有回収粒数の割合を掛ける。

探索は3段階で行う。まず2,500軌道を基準配置で3振り連成し、上位300件を3配置×5振り、上位100件を6配置×20振りで再評価する。後段には左右の片側クラスタと中央クラスタを含める。最終段階では最初の2振りをウォームアップとして採点から外すが、着地状態と損失は引き継ぐ。

各試行の合格条件は累積生存率80%以上、3振り移動窓の離床参加率の下位25%点60%以上、3振り以上連続して離床しない生存粒20%以下、一振り品質の下位25%点20%以上とする。重心や左右占有は合否・得点に使わない。合格配置数を最優先に、振りごとの回収・反転品質45点、全期間の交換経験20点、周期間の関係変化10点、各粒の移動範囲10点、生存10点、鍋運動効率5点で順位付けする。飛翔高さは採点外の観測値である。このスコアは物性の同定値ではなく、目視評価と実測によって更新する探索用ヒューリスティックである。

目視で「3回とも安定して舞い、前後が入れ替わる」と選んだ13軌道の記録と初期分析は [`selected-trajectories-analysis.md`](selected-trajectories-analysis.md) にまとめた。
同文書の追試では [`analyze-order.mjs`](analyze-order.mjs) で離床角と着床角のペア順序反転率を再現できる。

20回連続再生で米が片側へ寄るにもかかわらず高得点だった旧評価の原因と、現在の複数振り評価の設計は、[`search-evaluation-diagnosis.md`](search-evaluation-diagnosis.md) にまとめた。
