# 業務用中華鍋・論文再現モデル

## 目的と出典

Ko & Hu, “The physics of tossing fried rice” (2020), DOI `10.1098/rsif.2019.0622` の業務用鍋モデルを、家庭用片手鍋モデルの前段となる比較実験として実装する。原論文 PDF は `docs/rsif.2019.0622.pdf` に保存している。

## 実装した物理

- 鍋断面は論文の実測値（曲率半径 `L = 0.20 m`、幅 `0.37 m`、深さ `0.13 m`、半開口角 `ζmax = 1.2 rad`）による円弧とする。提供写真も、平らな縁から滑らかに丸底へつながる側面形状の定性的な確認に用いた。
- 鍋はコンロ縁との接触を保つ、長さ `L` の二リンク運動とする。角度は論文式 (3.1) の `θi(t) = θ̄i + Ai cos(2πft + φi)`、位置は式 (3.2) で計算する。
- 円弧上の21地点について、重力加速度と鍋表面加速度の差を内向き法線へ射影し、論文式 (3.5) を満たした最初の時刻に離床させる。
- 離床位置と速度は鍋面から引き継ぎ、空気抵抗と粒同士の衝突を無視して、重力 `9.81 m/s²` だけで式 (3.6) を積分する。刻み幅は論文と同じ `0.002 s`。
- 粒と移動中の鍋中心との距離が再び `L` になった時点を式 (3.7) の着地とし、開口角の外なら回収失敗とする。着地後の滑走は論文モデルの評価対象外なので、回収した標本は次周期の開始分布へ戻し、離床条件がいったん不成立になった後に同じ1周期の投射を再評価する。1セットは3周期として再生するため、これは3周期を連成して追跡するモデルではなく、論文の代表周期を3回可視化する近似である。

## 論文からの意図的な拡張

`付着抵抗 a` は、乾燥粒子で引力なしとする原論文にはない探索用パラメーターである。離床に必要な法線方向の相対加速度へ `a` を閾値として加える。`a = 0` が論文そのままの条件であり、結果画面でもこの差を明示する。

ランダム探索は周波数 `f`、振幅 `A1, A2`、位相差 `φ`、付着抵抗 `a` を振り、離床率、鍋内回収率、角移動量、過大でない飛翔高さを暫定採点する。この値は米の物性同定結果ではなく、離床と回収が両立する領域を見つけ、次の実測・家庭用モデルで検証するための候補である。
