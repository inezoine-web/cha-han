## 2026-08-16 — 上面視の機能試作へ縮小

- ゲーム的な残量ゲージや左右ボタンを外し、画面を上にして右手で持つ前提の円形・上面視ワイヤーフレームへ変更した。
- 一般的な丸底中華鍋を回転放物面として近似し、軽量な48粒の米に重力、鍋面の中心向き成分、摩擦、飛翔を適用する。厳密な粒子間衝突は試作段階では行わない。
- リセット操作を、米の再配置、モーションセンサー権限取得、最初のセンサー標本による水平基準調整の一連の入口に統合した。
- センサー強度を0.2〜2.5倍で調整できるようにし、センサーのない開発環境向けに円形領域のドラッグと4方向キーをフォールバックとして残した。
- `./scripts/build.sh` と `./scripts/check.sh` を通し、Playwright 1.62.1 と Google Chrome でモバイル表示、リセット、スライダー、ドラッグ操作を確認した。

## 2026-08-16 — 実鍋の体感から米の運動仮説を整理

- 調理時の観察として、米の集団は静置しても油のように中央へ流れず、鍋肌・粒同士・油や水分による降伏抵抗を持つという仮説を記録した。
- 鍋振りの主要因を単純な上下動ではなく、前進加速、前進減速、曲面上昇、離床、引き戻して回収する一連の位相として整理した。
- 次の試作候補として、有効重力 `g - A_w`、静止摩擦、固着・滑り・飛翔の状態遷移、移動する鍋との再衝突を `docs/rice-motion-model.md` にまとめた。
- これらは体感に基づく未検証のモデルであり、再現入力、センサー記録、実鍋の動画と照合して定数と妥当性を検証する。
