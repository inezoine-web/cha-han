# 米が舞うための共通因子 — 論文と参照動画の統合仮説

Date: 2026-08-20

## 目的

業務用中華レンジ上のプロ料理人を解析した Ko & Hu (2020) **The physics of tossing fried rice** と、`docs/reference-video-wok-motion.md` で分解した家庭用片手鍋に近い鍋振り動画は、鍋の拘束条件と見た目の軌道がかなり異なる。

それでも両者を「米がいつ鍋面から離れ、どの方向へ飛び、再び鍋へ戻るか」という観点で比較すると、共通する物理的な因子を抽出できそうである。

この文書では、特定の正解軌道を決めるのではなく、異なる鍋振りスタイルにも共通して使える離床・飛翔・回収モデルの仮説を整理する。

参照:

- `docs/rsif.2019.0622.pdf`
- `docs/fried-rice-paper-notes.md`
- `docs/reference-video-wok-motion.md`
- `docs/rice-motion-model.md`

## 二つの鍋振りは何が違うか

### 論文のプロ料理人

論文では、重い中華鍋をコンロの縁へ接触させたまま滑らせ、その接触点を利用してシーソー運動を作る。鍋の運動は二自由度の二リンク振り子として表現でき、主要パラメーターは運動周波数と二つの運動の位相差である。

代表値は約 3 Hz、位相差は約 1.0 rad。観測された料理人全体では鍋振り周波数は 2.7 ± 0.3 Hz だった。

### 参照動画の片手鍋

参照動画では、コンロ縁を固定支点にしたシーソーとは見えず、鍋の前後並進、短い上下並進、ピッチ回転が別々のタイミングで重なっている。

一振りは概ね、

1. 米を奥へ送る
2. 鍋を制動して米を奥側曲面へ走らせる
3. ピッチと短い上動を重ねる
4. 米を離床させる
5. 飛翔中に鍋を戻す
6. 落下する米を受ける

という非対称な位相列として見える。

したがって、鍋の絶対軌道や支点モデルをそのまま共通化するのは難しい。

## 共通因子 1: 米を離床しやすい場所へ運ぶ

論文では鍋底中央が `dead zone` になりやすく、外側ほど米が離床しやすい。参照動画でも、米をいきなり中央から真上へ飛ばすのではなく、まず奥側曲面へ送り込んでいるように見える。

共通する最初の工程は、

```text
鍋底付近の米
    ↓
曲率と面速度を利用できる領域へ移送
```

と考えられる。

つまり「飛翔」は一瞬のジャンプ操作だけではなく、その前の**助走・配置フェーズ**を含む。

## 共通因子 2: 接線方向速度を作る

論文では位相差 0 に近い運動では米は高く飛ぶが主に上下へ動き、混合量が小さい。一方、料理人が選んだ位相差では飛翔高さを多少犠牲にしながら鍋内の横方向移動量が大きくなる。

したがって、良い鍋振りを「最大飛翔高さ」で評価するのは適切ではない。

参照動画でも、前後送りと制動によって米を曲面に沿って走らせ、その接線速度を保ったまま離床へ移るように見える。

鍋表面上の接触点 `r` の速度は、並進と回転を合わせて

```text
V_surface = V_w + omega × r
```

と表せる。

局所接線 `t` に沿う速度

```text
v_t = V_surface · t
```

を、米が飛翔後に鍋内を移動・反転するための「助走速度」とみなす。

## 共通因子 3: 接線速度を持った状態で拘束を解く

論文の離床条件は、鍋表面の法線方向について鍋が米を押し続けられなくなることとして表現されている。簡略に言えば、接触を維持するために必要な法線力 `N` が 0 以下になる瞬間が離床である。

論文のほぼ水平な鍋面では、鍋面の下向き加速度が重力加速度を上回ることが離床条件につながる。実測されたプロの動作でも、鍋の方向転換時に約 1.5 g の減速が観察され、その後に米が投射運動へ入る。

参照動画では同じ離床状態を、前後制動、曲面、ピッチ、短い上下運動の組み合わせで作っている可能性がある。

したがって両者の共通因子は「どの軌道を描くか」ではなく、

```text
十分な接線方向速度を作る
          +
適切な時刻に法線拘束を失わせる
```

ことと考えられる。

概念的には、

```text
米が舞う ≒ v_t が十分大きい AND N <= 0
```

である。

ここで重要なのはピーク値だけではなく、**接線速度の生成と離床条件成立の位相差**である。

## 共通因子 4: 飛翔後の鍋運動も一振りの一部

論文の最適化には `failed catch` 領域が存在する。強く・速く飛ばせば常に良いわけではなく、飛翔した米が鍋へ戻れなければ失敗である。

参照動画でも、離床後に鍋を単に初期位置へ戻すのではなく、飛翔している米の下へ差し戻して着地時の相対速度を小さくする回収操作が見える。

したがって一振りは、

```text
助走
 → 離床
 → 低い飛翔と横移動
 → 鍋を着地点へ移動
 → 低い相対速度で回収
```

までを一つの閉じた運動として評価する必要がある。

## 共通因子 5: 位相が軌道形状より重要

論文では二つの運動の位相差が最重要パラメーターの一つとされている。同じような楕円軌道でも時間方向を反転すると米の飛び方が変わり、「楕円軌道であること」だけでは十分ではない。

これは参照動画の分析とも一致する。動画でも前後並進、上下運動、ピッチを同一波形・同一時刻で固定すると本質を失う。重要なのは、

```text
送り出し
 → 制動
 → ピッチ／すくい
 → 離床
 → 回収開始
```

の時間関係である。

このため、シミュレーションや探索では位置軌道そのものより、以下のイベント時刻を保存する方がよい。

- 接線速度ピーク
- 前後減速ピーク
- ピッチ角速度ピーク
- 法線力が 0 になる推定時刻
- 実際の離床時刻
- 回収開始時刻
- 再接触時刻

## 一般化した一振りモデル

現時点では、特定の「正解鍋軌道」を作るより、次の状態遷移として扱う方がよい。

```text
STUCK / SLIDING
    ↓  曲面側へ移動し接線速度を得る
PREPARED
    ↓  N <= 0
AIRBORNE
    ↓  重力下の投射 + 動く鍋との交差
LANDED
    ↓  非弾性衝突 + 滑り
STUCK / SLIDING
```

鍋側はスタイルに応じて自由に動いてよい。業務用の固定支点シーソーでも、家庭用の並進＋ピッチでも、各接触点の表面速度・加速度を計算できれば同じ米側モデルへ入力できる。

## 探索・学習で重視したい変数

GA、ランダム探索、将来的な機械学習で鍋振り波形を探す場合、絶対位置の軌道点列をそのまま遺伝子にするより、次の特徴量を優先する。

- 離床直前の接線速度 `v_t`
- 接線速度ピークから離床までの時間差
- 減速ピークからピッチ角速度ピークまでの時間差
- 離床位置
- 離床時の速度ベクトル
- 飛翔高さと滞空時間
- 離床位置から着地点までの鍋内移動量
- 着地時の相対法線速度
- 回収率、損失率
- 周期間の再現性

特に、

```text
接線速度最大時刻 ↔ N = 0 となる時刻
```

の位相差を主要な探索変数にする価値がある。

## 暫定評価関数

「米が高く飛ぶ」ではなく「炒めるために良く舞う」を狙うなら、評価は例えば次の合成にする。

```text
score =
    飛翔した割合
  + 鍋内の前後／上下層入れ替わり
  + 適度な横方向移動量
  + 中央付近への回収率
  - 過大な飛翔高さ
  - 着地時の相対法線速度
  - 鍋外への損失
  - 周期間のばらつき
```

重みはまだ物理定数ではなく、動画・実鍋・プレイ感との比較で決める。

## 現時点の中心仮説

二つの異なる鍋振りから得られる最も一般化しやすい仮説は次である。

> **良い鍋振りとは、米を曲面上で加速して接線方向の運動量を与え、その運動量が残っている適切な瞬間に法線方向の拘束を解き、飛翔中に鍋を回収位置へ移動させる動作である。**

つまり再現すべきものは「プロと同じ鍋軌道」ではなく、

```text
助走 → リリース → 飛翔 → 回収
```

の物理条件と位相関係である。

この整理なら、業務用シーソー式と家庭用片手鍋式を同じ米モデルで比較でき、スマホによる鍋振り練習にもつなげやすい。

## 注意点

この文書のうち、論文の測定値・離床条件・位相差に関する記述は Ko & Hu (2020) に基づく。一方、参照動画との共通因子、`v_t` と `N` を中心にした一般化、探索変数・評価関数は現時点の仮説であり、論文が直接検証した結論ではない。

次の検証では、参照動画のフレーム追跡と実鍋の IMU 記録を用いて、離床直前の接線速度、減速、ピッチ、離床時刻の位相関係が実際に再現するか確認する。
