# 米の挙動モデルに関する観察と仮説

Date: 2026-08-16

## この文書の位置づけ

実際の中華鍋でチャーハンを作るときの体感を、次のシミュレーションを設計するための仮説として整理する。ここに記す内容は計測済みの物理定数や確定仕様ではない。再現可能な入力波形、実鍋の動画、端末センサーの記録と照合しながら検証する。

## 調理時の観察

- 米の集団は油のようには流れず、鍋を静置しても直ちに中央へ集まらない。
- 米を舞わせる主な操作は単純な上下動ではなく、鍋の前後動、とくに前へ突き出した動きを減速するタイミングにある。
- 前へ加速し始めたとき、米は慣性で鍋に置いていかれようとするが、鍋肌や周囲の米との抵抗によってしばらく追従する。
- 前進を減速すると、米は鍋に対して前へ進み、丸い鍋底に拘束されることで曲面を登る。
- 近いタイミングで鍋を軽く上へ振ると、米は曲面に沿って得た速度を保ちながら鍋を離れる。
- 各粒の接触状態が異なるため、滑り始めと離床は一斉ではない。この時間差が米の入れ替わりやシャッフルを生む。
- 飛翔中に鍋を適切な位置へ戻し、相対速度を合わせることで米を受ける。

ここでいう「米の抵抗」は一粒だけの性質ではなく、米と鍋肌の摩擦、粒同士の摩擦や噛み合い、油・水分・でんぷんによる軽い粘着、米の山を変形させる内部抵抗を合わせたものと考える。

## 最小の力学モデル

まず取っ手方向の鉛直断面を2次元で扱う。身体から鍋を遠ざける方向を \(x\)、上方向を \(z\) とする。鍋の並進位置を \(\boldsymbol X_w(t)\)、加速度を \(\boldsymbol A_w(t)\) とすると、鍋とともに動く座標系で米が受ける有効重力は

\[
\boldsymbol g_{\mathrm{eff}}=\boldsymbol g-\boldsymbol A_w
\]

となる。前進を減速する区間では \(A_{w,x}<0\) なので、米には鍋に対して前向きの慣性力 \(-mA_{w,x}\) が働く。前進速度だけでなく、加速、減速、回収の位相を入力として残す必要がある。

鍋の断面を

\[
z=f(x)
\]

とすると、単位接線ベクトルは

\[
\boldsymbol t=\frac{(1,f'(x))}{\sqrt{1+f'(x)^2}}
\]

である。鍋面に沿う速度を \(v_t\) とすると、その上向き成分は

\[
v_z=\frac{v_t f'(x)}{\sqrt{1+f'(x)^2}}
\]

となる。この拘束によって、鍋に対する前向きの運動が曲面上で上向きの運動へ変換される。上下入力は米へ直接加えるのではなく、接触中の法線力、鍋面速度、離床条件を通じて渡す。

## 固着、滑り、飛翔

粒 \(i\) の状態を少なくとも `STUCK`、`SLIDING`、`AIRBORNE`、`LOST` に分ける。

### 固着と滑り

接線方向の駆動力を \(F_{t,i}\)、法線力を \(N_i\)、静止摩擦係数を \(\mu_{s,i}\)、粒集団による簡易な凝集抵抗を \(C_i\) とする。

\[
|F_{t,i}|\leq \mu_{s,i}N_i+C_i
\]

の間は鍋面に対して静止させ、これを超えたときだけ滑りへ移す。この降伏条件により、小さな傾きや重力成分だけで米が中央へ流れ続けることを防ぐ。

滑っている間の面方向運動は、概念的には

\[
m_i\dot v_{t,i}=m_i\boldsymbol g_{\mathrm{eff}}\cdot\boldsymbol t_i
-\mu_{k,i}N_i\operatorname{sgn}(v_{t,i})+F_{\mathrm{neighbors},i}
\]

と表せる。最初の実装では厳密な粒子間衝突の代わりに、\(C_i\) と弱い近傍相互作用で集団の抵抗を近似してよい。

### 離床と飛翔

鍋は米を押せても引けないため、接触維持に必要な法線力がなくなる

\[
N_i\leq 0
\]

付近を離床条件とする。離床時の世界座標速度は、鍋面の速度 \(\boldsymbol V_{\mathrm{surface}}\) と面方向の相対速度を合成して

\[
\boldsymbol v_{i,\mathrm{world}}=\boldsymbol V_{\mathrm{surface}}+v_{t,i}\boldsymbol t_i
\]

とする。飛翔中は重力だけを適用し、移動している鍋面との交差を再接触として扱う。

### 回収

着地の成否は、米だけでなく同時刻の鍋位置で決まる。着地時刻を \(t_{\mathrm{land}}\) とすると、鍋中心に対する相対位置

\[
\boldsymbol r_{i,\mathrm{rel}}=\boldsymbol x_i(t_{\mathrm{land}})-\boldsymbol X_w(t_{\mathrm{land}})
\]

が安全な領域内にあり、かつ米と鍋面の相対法線速度が大きすぎないことを良い回収の条件とする。したがって訓練評価では、押し出しの強さだけでなく、減速、離床、鍋を引き戻す時刻の関係を評価する。

## 粒ごとのばらつきとシャッフル

すべての粒を同じ時刻に滑らせない。粒ごとに初期位置、静止・動摩擦係数、凝集抵抗、反発係数を少し変え、近傍粒子から受ける力も加える。これにより滑り開始時刻と離床時刻に差が生まれる。

「シャッフル」は米全体の剛体回転だけを意味しない。下層と上層の速度差、離床時刻と飛翔時間の差、異なる場所への再着地によって粒の並びが入れ替わる現象も含める。将来3次元化する場合は、中心まわりの角運動量

\[
L_z=\sum_i m_i(x_iv_{y,i}-y_iv_{x,i})
\]

に加え、一振り前後の粒の順位や近傍関係の変化をシャッフル指標の候補とする。

## 現行試作との差分

現行試作は接触中の粒へ常に中心向きの成分を加え、上方向の入力を粒の鉛直加速度へ直接加えている。このため、静置時に中央へ寄りやすく、前後動がなくても上下入力だけで飛翔できる。

次の試作では以下を優先する。

1. 常時の中心向き復元力を、鍋加速度を含む有効重力の接線成分へ置き換える。
2. 静止摩擦と降伏条件を導入し、弱い力では米を動かさない。
3. 鍋の前後速度と加速度を短い一振りの間だけ追跡し、前進加速と前進減速を区別する。
4. 上下入力を直接の飛翔力ではなく、接触力と離床タイミングへ反映する。
5. 粒を固着、滑り、飛翔、消失の状態に分ける。
6. 粒ごとのパラメーター差で、時間差のある離床とシャッフルを作る。
7. 再現可能な入力波形で、押し出し、減速、軽い上振り、回収の位相を個別に検証する。

## 検証が必要な点

- 米が動き始める加速度と鍋角度のしきい値。
- 油量、水分、米量、温度による静止・動摩擦と凝集抵抗の変化。
- 前進減速と上振りの時刻差が離床速度へ与える影響。
- 鍋のピッチ回転を並進運動と別にモデル化すべきか。
- 粒子間衝突を省略した近似で、集団の循環と着地の散らばりを十分表現できるか。
- 実鍋の断面、センサー波形、動画から各パラメーターをどう推定するか。
