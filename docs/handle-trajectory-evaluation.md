# 業務用鍋軌道を家庭用の持ち手で評価する方法

Date: 2026-08-24

## 目的

業務用モードの軌道は、鍋底付近がコンロ縁に接触する二リンク機構を前提とする。米がよく舞う軌道が見つかっても、片手鍋として人が再現できるとは限らない。そこで鍋の右縁へ家庭用鍋風の持ち手を仮設し、握り位置の運動を独立に観測する。

## 現在の簡易評価

- 円弧の右縁から、その場所の接線方向へ長さ18 cmの直線状の持ち手を付ける。
- 鍋縁から16 cmの点を握り中心とする。
- 一周期を240区間で標本化し、握り中心の平均位置からのRMS距離を「支点ずれ」とする。
- 軌道の幅、高さ、一周期の道のり、最大速度、最大加速度、鍋の角度振幅も併記する。
- 画面では握り中心を橙点、一周期の軌跡を薄い橙線で描く。

「持ち手位置が概ね支点」という仮説に対して最も直接的なのは支点ずれである。現行表示の「支点近似の候補」は、支点ずれRMS 5 cm以下、最大速度2 m/s以下、最大加速度30 m/s²以下をすべて満たす場合だけとした。ただし、これらは候補の絞り込み用の暫定閾値であり、人間工学的な安全基準や実測限界ではない。

## 解釈上の注意

握った手は完全固定ではなく、肩・肘・手首を組み合わせて並進も回転もできる。このためRMSが大きいだけで「人には不可能」と断定できず、逆に小さいだけで鍋の質量・慣性モーメント・握力・手首トルクが許容範囲とは限らない。また業務用モデルの3 Hz運動をそのまま家庭用鍋へ要求すること自体が厳しい可能性がある。

次段階では、実鍋の質量と重心を加え、握り中心まわりの必要トルクと反力を計算する。さらに実際の鍋振り動画またはIMUから手の可動範囲、速度、加速度を取得し、暫定閾値を実測分布へ置き換える。その上で不成立なら、業務用軌道の位相関係など米を舞わせる要素だけを家庭用の自由な並進・回転モデルへ移植する。
