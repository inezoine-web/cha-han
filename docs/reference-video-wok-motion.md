# 参照動画から分解する鍋の運動要素

Date: 2026-08-20

参照: [YouTube Shorts `Nc13i11d6R0`](https://youtube.com/shorts/Nc13i11d6R0)

## 目的と読み方

参照動画の鍋振りを、見た目をそのままアニメーションへ写すのではなく、シミュレーションの入力と検証項目へ分解する。ここで扱うのは単眼動画から読める**定性的な順序と連動**であり、加速度、距離、角度の実測値ではない。画角、遠近、手や食材による遮蔽があるため、数値は今後のフレーム追跡と実鍋・端末センサーの同時計測で確定する。

動画は「正解動作の唯一の標本」ではなく、現行文書で不足していた自由度、拘束、位相を洗い出す参照標本として使う。

## 動画から分けて扱うべき運動

取っ手の付け根から鍋の奥側へ向かう水平軸を (x)、鉛直上向きを (z)、鍋の左右方向を (y) とする。

### 1. 前後並進 (x_w(t))

- 鍋を奥へ送り出す区間と、その動きを止める区間を別の入力として扱う。
- 食材を奥側の曲面へ走らせる主要なきっかけは、位置そのものではなく送り出し後の減速、すなわち (a_x(t)) の符号とピークである。
- 戻しは単なる初期位置への復帰ではない。飛翔した食材の下へ鍋を差し戻し、着地時の相対速度を小さくする回収操作である。

したがって正弦波一つではなく、少なくとも「送り出し」「制動」「回収」の非対称な3区間が必要になる。

### 2. 上下並進 (z_w(t))

- 上方向の運動は、食材へ直接ジャンプ力を加える独立ボタンとして扱わない。
- 制動と曲面上昇に重なる短い持ち上げは、接触面速度と法線力を変え、離床の時刻と速度へ寄与する。
- 回収時には鍋を食材へ打ち付けず、落下に合わせて受ける下向き成分も候補になる。

重要なのは上下変位の大きさより、(a_x(t)) と (v_z(t)) のピークの時間差である。

### 3. ピッチ回転 \(\theta(t)\)

- 取っ手を上下するピッチは、鍋底と奥側の縁で異なる表面速度を作る。
- 奥側を立てる回転は食材を曲面に沿わせる局面に、戻す回転は食材を鍋内へ受ける局面に関係する。
- 並進と回転を同じ時刻・同じ波形に固定しない。減速ピーク、角速度ピーク、離床の順序を独立に記録する。

回転を含む接触点 $\boldsymbol r$ の表面速度は

\[
\boldsymbol V_{surface}=\boldsymbol V_w+\boldsymbol\omega\times\boldsymbol r
\]

となるため、並進だけのモデルでは奥側斜面が食材へ与える速度を再現できない。

### 4. 支点が移る回転

手首だけを中心に鍋全体が回ると仮定しない。操作中は、握り手、取っ手付け根、鍋底付近のどこを見かけの支点とみなせるかが変わる。並進 (x_w,z_w) とピッチ \(\theta\) を独立自由度として持たせれば、この「移動する瞬間中心」を表現できる。

業務用レンジの縁を固定支点とするモデルとも区別する。片手鍋では支点拘束を先に決めず、追跡結果から並進と回転の組み合わせとして同定する。

### 5. ロールとヨー

動画の主運動は取っ手方向の断面で近似してよいが、左右の傾き（ロール）と水平面内の向き（ヨー）を「存在しない」とはしない。

- 左右の縁高さに差が出れば、食材の横流れと片側からの損失が起きる。
- 周期ごとの小さなヨーは、食材の3次元的な入れ替わりに寄与し得る。
- 2D試作では外乱・損失要因として記録し、3D化するまでは成功に必須の入力へしない。

## 一振りを位相で表す

動画の見た目を再現するには、次の状態機械として整理する方が、単一の「振り強度」より適している。

| 位相 | 鍋の運動 | 食材の相対運動 | モデルで見る量 |
| --- | --- | --- | --- |
| 0. 準備 | 低い速度で姿勢を整える | 鍋底付近でまとまる | 初期位置、初期ピッチ、固着率 |
| 1. 送り出し | 奥向き速度を作る | 摩擦・凝集により遅れて追従 | (v_x,a_x)、降伏開始 |
| 2. 制動・斜面上昇 | 奥向き運動を急に弱める | 慣性で奥側曲面を登る | 減速ピーク、接線速度、到達位置 |
| 3. すくい・離床 | 短い上動とピッチを重ねる | 曲面接線方向の速度を保って離れる | $v_z,\omega_y,N$、離床時刻 |
| 4. 飛翔・反転 | 鍋を食材の下へ戻し始める | 重力下で低い弧を描き、層が入れ替わる | 飛翔高、滞空時間、角運動量 |
| 5. 回収・吸収 | 落下位置と速度へ鍋を合わせる | 内面へ再接触し、滑って中央へ戻る | 着地点、相対法線速度、反発 |
| 6. 次周期への接続 | 姿勢と位置を準備状態へ戻す | 再びまとまり、次の送り出しへ | 周期、残留振動、再現性 |

境界時刻は鍋の波形だけから固定せず、米の `STUCK` / `SLIDING` / `AIRBORNE` の遷移と合わせて決める。特に位相2と3は一部重なり得る。

## 鍋だけでなく、食材との相対運動を追う

同じ鍋軌道でも摩擦、量、水分、初期位置によって返り方は変わる。動画照合では最低限、次のイベントを鍋のイベントと同じ時間軸へ置く。

- 食材前端が奥へ滑り始める時刻
- 食材重心が鍋底を通過する時刻
- 奥側曲面での最大到達位置
- 最初と最後の離床時刻（離床の時間幅）
- 食材重心の頂点と最大飛翔高
- 最初と最後の再接触時刻（着地の時間幅）
- 着地点と鍋中心の距離
- 一振り前後で上下層・前後位置がどれだけ入れ替わったか
- 縁を越えた割合

全粒が同時に剛体として反転するとは限らない。まとまりの前端と後端の離床時刻の差、飛翔中の伸び、着地時の広がりを持たせる必要がある。この差を消してしまうと、軌道は似ていても「炒める」ための混合を評価できない。

## 現行シミュレーションへの示唆

### 入力波形

現行の自動一振りを、強度だけでなく以下のパラメーターへ分解する。

1. 送り出し時間と最大速度
2. 制動開始時刻、継続時間、ピーク減速度
3. 上動開始時刻とピーク速度
4. ピッチ開始時刻、角速度、角度範囲
5. 回収開始時刻、位置、速度
6. 次周期までの整定時間

探索時には各ピーク値だけでなく、`制動 → ピッチ → 離床 → 回収` の時間差を保存する。

### 物理モデル

- 鍋姿勢を固定した上下・前後並進だけでは不十分なので、ピッチを次の主要自由度にする。
- 接触判定では回転する面の速度を用い、離床条件は有効重力、曲率、接線速度から得る法線力で決める。
- 回収は「粒が鍋領域に入った」だけで成功にせず、接触位置と相対法線速度を評価する。
- 粒ごとの離床・着地時刻の幅を保ち、まとまりを完全な剛体にしない。
- 反復動作では一振りの最終状態を次周期の初期状態として引き継ぐ。

### センサー入力と採点

スマートフォンでは長時間の位置積分を避け、各周期内の特徴量として扱う。

- 加速度: 送り出しと制動のピーク、上下成分、各ピークの時刻
- ジャイロ: ピッチ角速度ピーク、回転方向、回転量の短時間積分
- 位相: 減速ピークからピッチピークまで、ピッチピークから推定離床まで、離床から回収開始まで
- 安定性: 周期、ピーク、位相差の周期間ばらつき
- 不要運動: ロール・ヨーの大きさと、左右損失につながる偏り

採点は大振りを促さず、低い飛翔、中央付近への低相対速度での回収、十分な入れ替わり、周期間の再現性を組み合わせる。

## 動画から断定できないこと

単眼のShortsだけでは次を決めない。

- 実距離、速度、加速度、力、鍋重量
- カメラ奥行き方向の移動量
- 見えない接触点と握力・手首トルク
- 食材と鍋の摩擦係数、凝集力、反発係数
- 編集による速度変更やフレーム欠落の有無
- 一つの成功例が再現可能な最適動作であるか

これらを動画に合わせて恣意的に調整すると過学習になる。参照動画は運動要素とイベント順序の仮説を作るために使い、定数同定には使わない。

## 次の計測手順

1. 元動画をフレーム単位で確認できるローカル参照物として用意し、編集や再配布はしない。
2. 画面上で「鍋底中心」「取っ手付け根」「奥縁」「食材重心」を各フレームに打点する。
3. 鍋の既知寸法が得られる場合だけ画素を実長へ換算し、得られなければ鍋径で正規化する。
4. 座標を平滑化してから位置、速度、加速度、ピッチ角を推定し、平滑化条件も保存する。
5. 一振りの開始を0、次周期開始を1とする正規化時刻でもイベント表を作る。
6. シミュレーションへ同じ鍋軌道を入力し、離床・頂点・着地の順序と相対位置を比較する。
7. 最後に、実鍋へ固定したIMUまたはスマートフォンの記録と同期し、単眼動画では曖昧な加速度と回転を校正する。

最低3周期を追跡し、平均だけでなく周期間の幅を残す。目標は動画の画素軌道への完全一致ではなく、同じ位相関係から同程度の低い飛翔と回収が繰り返し生じることである。
